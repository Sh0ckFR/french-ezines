Bonjour à tous! Comme dirait l'autre, un hacker qui s'ennuie est un hacker qui
peut trouver des trucs.

Chaque bidouilleur a son moyen préféré de passer le temps sur de la cyber.
Il y en a qui font du web quand ils s'ennuient, il y a les malades du cerveau 
qui font du pwn, d'autres qui font du reverse de jeux, moi personnellement ce 
que j'aime faire quand je n'ai plus d'inspiration, c'est d'arpenter les moteurs
de recherche d'IP publiques. J'ai dû y passer plusieurs centaines d'heures. 

Chacun son kink.

Je vais donc ici essayer d'expliquer pourquoi je trouve ça cool et ma démarche 
de recon quand on n'a aucun objectif, vous allez voir au début, c'est plus une 
démarche maïeutique (le truc de Socrate là), qu'une démarche technique.

Pourquoi c'est cool ?

Personnellement, se perdre sur Google, Shodan ou autre moteur de recherche, 
c'est un peu un retour en enfance, tu découvres un endroit, il y a plein de 
trucs partout, tellement de trucs partout que tu peux juste regarder ce qu'il
y a et repartir pour faire la même chose autre part.

C'est comme découvrir que la maison des grands-parents a un grenier, et que tu 
as enfin le droit d'y aller pour fouiller, chaque trouvaille peut se trouver
être des trésors.

L'idée de base est donc d'explorer internet et à partir d'une idée de base 
courir dans le sens qu'on veut.

Socrate, il vient faire quoi là-dedans ?

La maïeutique, pour faire court, c'est le concept de faire accoucher 
l'esprit d'une personne d'une vérité qu'il possède déjà.

Pour cet article je vais prendre l'exemple d'un sujet que j'aime bien, les 
systèmes cyber-physiques (Système matériel et logiciel qui collecte et traite 
les données d'un ou de plusieurs objets connectés et commande les actionneurs 
nécessaires à leur fonctionnement.)

Je sais que ces systèmes pullulent sur internet, et il y en a tellement que je
ne sais pas par où commencer.

Donc on va essayer de créer un cheminement cognitif autour de ce concept de 
système cyber-physique (SCP).

(pour ceux qui n'ont pas la réf qui va suivre, jouez à Disco Elysium)

Donc on trouve facilement le site de Geneko (https://www.geneko.rs/), et là on 
va commencer simple, comme le mec qui a fait tomber YGG, on va commencer par 
un favicon. On va essayer d'appliquer la théorie suivante, dans les systèmes 
embarqués il y a de grandes chances d'avoir un serveur web, il y a donc un monde
où un constructeur d'équipements réutilise des favicons.

Donc on trouve un moyen de récupérer le favicon du site web, avec ça on peut
commencer à pivoter

- https://www.geneko.rs/favicon.ico

Il existe plein de solutions pour générer un hash de favicon, personnellement 
j'utilise ce site web.

- https://favicon-hash.kmsec.uk/

Ok, donc c'est cool, on peut se rendre compte que le site web de Geneko utilise 
le même favicon pour ses produits. Si vous voulez extraire les informations de 
Shodan et que vous avez un compte, vous pouvez utiliser ce script

```python
import shodan  
  
SHODAN_API_KEY = 'API'  
FAVICON_HASH = 1490525349   
  
api = shodan.Shodan(SHODAN_API_KEY)  
LIMIT = 400  
  
def search_by_favicon_hash(favicon_hash, limit=400):  
    query = f'http.favicon.hash:{favicon_hash}'  
    count = 0  
    servers = []  
    for result in api.search_cursor(query):  
        if count >= limit:  
            break  
        ip = result['ip_str']  
        port = result['port']  
        servers.append((ip, port))  
        count += 1  
    return servers  
  
if __name__ == '__main__':  
    servers = search_by_favicon_hash(FAVICON_HASH, LIMIT)  
    with open('ip_port_shodan.txt', 'w') as f:  
        for ip, port in servers:  
            f.write(f'http://{ip}:{port}\n')
```

Donc on a maintenant une liste d'IP et de ports. Mais les faire à la main c'est 
laborieux et je n'ai pas envie de perdre du temps avec cela. Pour pallier à ce 
problème j'utilise GoWitness

https://github.com/sensepost/gowitness

GoWitness est un outil de screenshots web basé sur Golang, il utilise Chrome 
headless. Si vous êtes sous Kali Linux, un simple "apt install gowitness" 
devrait faire l'affaire.

```
gowitness scan file -f FILENAME.txt 
```

Voilà, avec ça vous avez un bon visuel de ce qu'il y a.

Si on place un proxy (Burp Suite) pour une tentative de connexion, on se rend 
compte que notre mot de passe et username sont en base 64, ça veut dire que le 
chiffrement des credentials se fait en local puis est envoyé sur le serveur.

Quand on cherche un peu les appels JS on tombe sur /lib/gwr.js, un gros blob de
JS de plusieurs milliers de lignes. Et dedans il y a une petite surprise, une 
petite fonction nommée hpasswd

```js
function hpasswd(a) {
	a = a.split("");
	var b = a[0],
		d = a[4],
		e = a[3];
	a[0] = a[2];
	a[2] = b;
	a[3] = d;
	a[4] = e;
	a.join("");
	b = [];
	d = Math.round(a.length / 2);
	for (e = 0; e < a.length; e++)
	if (e < d) {
		var f = a[e].charCodeAt(0),
			g = 33;
		120 >= f && (g = f + 5);
		b.push(a[e]);
		b.push(String.fromCharCode(g))
	} else b.push(a[e]);
	return b.reverse().join("")
}

```

Vous l'aurez compris, c'est la fonction de hash de mot de passe, qui est plus un
scramble qu'autre chose. Donc avec ça, on active le mode bruteforce si on était
des méchants, mais ce n'est pas notre cas, donc on va s'arrêter là.

C'est court, et je n'explique pas tout, mais l'idée est là. Si vous voulez 
trouver un truc sur internet vous le trouverez, mais il faut avoir l'idée de 
chercher et surtout de quoi chercher.
